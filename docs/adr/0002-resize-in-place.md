# Resizing changes a Design in place

Resizing a Design changes its Format and scales its Elements proportionally. It does not create a new Design, unlike Canva's resize, which makes a copy. We keep one Design so its Comments, Snapshots and sharing stay in one place.

Elements left fully outside the Page are hidden rather than deleted, so resizing never loses content. Resizing again shows them if they fit inside the Page, but never Elements a user hid by hand. The Layers panel lists all Hidden Elements in their own section, where users can select them together and delete them. That section is only a view; it does not change the Design's structure.
